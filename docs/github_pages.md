# Project website

https://kevinyamada.github.io/canadian-household-finance/

GitHub Pages serves the main branch's /docs folder. The page follows the housing-readiness audit, with an interactive provincial map, national renter income/consumption graph, purchase-cash scenarios and Power BI download.

- `docs/index.html`: content and accessible navigation.
- `docs/assets/style.css`: responsive light/dark styles and print styles.
- `docs/assets/theme.js`: the small theme button. Fresh visits start in light mode, regardless of the system setting. An explicit choice is remembered in local storage.
- `docs/assets/visuals.js`: map selection, survey years, zoom and chart controls.
- `docs/assets/visuals-data.json`: saved estimates, scenarios and SVG coordinates generated by `src/site_visuals.py`.
- The main report download remains the focused v2.0.0 PBIX.
- The site has no analytics, external font requests, map API keys or client-side financial-rule calculations.

The map shows published renter core housing need for ten provinces. Territories retain their geography but have no survey estimate. The budget graph is national; selecting a province does not filter it. Purchase prices and closing allowances are explicitly illustrative.

The page is a published snapshot. After a source or rule update, review figures, dates, assumptions and report release together. [Source and visualization methods](website_visuals.md).

Preview from VS Code with `python -m http.server 8765 --directory docs`, then visit http://localhost:8765. The **Generate website map and charts** and **Check project website** VS Code tasks prepare and verify the site locally.

The browser check uses a separate headless Chrome or Edge on the user's PC. It checks desktop/phone widths, both themes, light mode on a fresh visit with a dark system preference, reload persistence, map/year/bar selection, missing territory estimates, zoom, chart selections, the purchase-rule boundary and agreement with saved audit data.
